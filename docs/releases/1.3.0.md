The insights panel is rebuilt around one idea: a card should say what it noticed and what it
costs you to act on it. The old panel offered one kind of card — a connection the vault did not
know about — and there are now nine, grouped into four tabs, ordered by severity and then by how
much work the card is.

> The interface strings for this feature are Chinese. The English column below is a translation
> for this document only.

## The panel

Four tabs, each answering a different question:

| Tab | Cards |
|---|---|
| **建议新增** (suggested new links) | 正文提及 N 处但未链接 — a page's name written in prose without a link · 共享 N 个邻居 — two pages with many shared neighbours and no link between them · 疑似重复页 |
| **惊奇连接** (surprising links) | Links you *already* wrote, scored for crossing a community boundary, joining distant page types, and sharing sources. This is the previous release's list, given its own tab — it had been buried under newer cards |
| **结构风险** (structural risks) | 单点故障 (removing the page disconnects part of the graph) · 集群门户 (a whole area reachable through one page) · 连接不足的枢纽 (more structure than its link count suggests) · 中介节点 (sits between groups that do not talk to each other) |
| **知识空白** (knowledge gaps) | N 个孤立页面 · 稀疏知识领域 · 关键桥接 |

Every card carries an evidence badge (`强证据` / `中等证据` / `弱证据`) and a cost badge — **一键**
(one click), **需编辑**, or **需撰写** — and the ordering respects the cost: at the same severity,
the cards you can clear in one click come first.

Dismissals are applied live against your current settings, so a card you dismiss stays dismissed
across rebuilds. The tab labels count what is left.

## Acting on a card, not just reading it

A card whose link can be inserted without writing anything gets an **插入链接** button. It shows
the exact line before and after, with the new link highlighted, and writes only when you confirm.
The insertion goes through Obsidian's vault API, so it lands in the editor's own undo history —
Ctrl/Cmd+Z takes it back.

The insertion keeps your words. If a note writes `偏好优化（DPO）` and the page is called
`RLHF 与 DPO`, the result is `偏好优化（DPO）（[[RLHF 与 DPO]]）`: the link is *added beside* what
you wrote, never substituted for it. The same holds when a page's name differs from the words in
the sentence, and when a note writes a name in a different case.

Other cards offer **并排打开** (both notes side by side), **create an index note**, or **export**.

## Faster

The graph and the analysis are cached, and a rebuild no longer blocks the view: the panel keeps
showing the previous findings while a new pass runs, and vault changes mark the cache stale
rather than re-running the analysis on every keystroke.

## Fixed

- The insight panel's width is fixed and no longer follows its pane, and its cards are one width
  across every group. Cards used to change width between tabs because a group whose content
  overflowed gave 14 px to the scrollbar while a short group gave none — measured in a real
  vault, 266 px against 278 px.
- The panel is no longer cut off in a narrow pane.

## Built, but not reachable in this release

Said plainly rather than left for you to discover:

- **The trends tab is empty, and correctly so.** 长期孤立页面 and 久未更新的枢纽 need page ages;
  on a three-day-old vault nothing has aged past the thresholds. 新兴主题 and 衰退主题 need a
  history of when each link first appeared — the detection is written and tested, but nothing
  calls it yet, so **no history file is being written**. Those two cards cannot fire until that
  is wired up.
- **The exported report still covers the two original sections.** The panel shows nine card
  types; the report has not been extended to match.
- **Panel contents can reshuffle.** Measured: dropping 2 % of a vault's links keeps about 2.5 of
  the panel's 6 cards. Dismissals survive a rebuild intact, but a materially changed graph can
  reorder a group.
