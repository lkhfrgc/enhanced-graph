把关联度计算、社区发现与图谱洞察叠加到内置的关系图谱上，同时提供一个功能更完整的独立视图。

> 这是第一个真正可安装的版本。1.0.0 因插件描述中含有 "Obsidian" 一词被目录自动审核退回，1.0.1 修正后重新提交。

## 功能

### 关联度引擎

任意两个页面之间的关联度由四路信号加权求和：

| 信号 | 默认权重 | 说明 |
| --- | --- | --- |
| 直接链接 | ×4.0 | 通过 `[[wikilinks]]` 相连；双向得满值，单向得一半 |
| Adamic-Adar | ×2.0 | 共同邻居按度数加权，越少见的邻居越有说服力 |
| 来源重叠 | ×2.0 | 共享同一条 `frontmatter sources[]` |
| 共被引 | ×1.0 | 被同一篇笔记引用的两篇笔记 |

**每路信号先归一化到 0–1 再加权**，所以权重就是相对重要性，浮层里的各项分数可以直接互相比较。悬停任意一条边可看到完整拆解，权重可在设置或视图面板里实时调整。

### 社区发现

Louvain 聚类，附内聚度与平均内部度——后者与社区规模无关，可以跨社区比较。

### 图谱洞察

- **惊奇连接**：跨社区、跨类型的意外关联
- **知识空白**：孤立页面 / 稀疏领域 / 桥接页面
- 每条都可以标记为已读

### 内置图谱增强（可选，默认关闭）

在 Obsidian 原生关系图谱上叠加社区着色、关联度浮层、洞察侧栏与点击聚焦。开启后会覆盖官方图谱的 color groups 着色，关闭时逐个还原。

### 独立视图

工具栏、过滤器（类型 / 标签 / 结构 / 孤立）、外观面板、权重面板、右键聚焦与两点连通、关联度报告导出为 Markdown。

## 安装

下载本页的三个文件 —— `main.js`、`manifest.json`、`styles.css` —— 放进：

```
<你的仓库>/.obsidian/plugins/enhanced-graph/
```

重启 Obsidian，在 `设置 → 第三方插件` 里启用。

尚未上架社区插件市场。

## 验证

仓库自带可复现的验证，不依赖人工目测：

```
npm run verify            类型检查 + 单测 + 真实仓库断言
                          + 浏览器 harness + 打包产物冒烟
npm run verify:obsidian   在真实 Obsidian 里跑断言，并打印被验证的版本号
```

已在真实 Obsidian **1.9.10** 与 **1.14.4** 上验证通过。`minAppVersion` 设为 1.9.10。

**未测过的版本不在此列。** 内置图谱增强与 Obsidian 版本绑定，运行环境不支持时会自动降级关闭，官方图谱本身完全不受影响。

## 已知限制

- **内置图谱只画真实存在的 `[[wikilink]]`。** 关联度引擎里最有价值的非链接关联（来源重叠、共同邻居、共被引）在内置图谱上没有对应的边，**只能在独立视图里看到**。
- **「相关笔记」可能少于 5 条。** 总分为 0 的配对被排除，而不是给一个保底分数——宁可少给，不给无意义的推荐。
- 大仓库首次建图需要一点时间，界面会显示进度。
