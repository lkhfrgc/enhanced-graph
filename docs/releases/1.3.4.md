The built-in graph could go completely blank after clearing the tag filter, and it stayed blank
after the enhancement was switched off. Both are fixed; the second is what made it look
permanent.

## A blank built-in graph after 全清 in 「包含标签」

With the tag filter in include mode (`包含标签`), pressing `全清` emptied the tick list. That
empty list was read as "keep nothing", so every node was filtered out of the data handed to the
built-in graph: the canvas, the toolbar and the insights panel were still there, the graph was
not. The hint under the mode toggle says the opposite — "with none ticked nothing is filtered" —
so the state could be reached by following the interface's own instructions.

An empty selection now means what the hint says: the tag filter is not in use, and every page is
kept. A vault that already has an empty include list saved needs no action — the built-in graph
is back on the next load.

`全清` in `包含标签` therefore switches the tag filter off rather than hiding everything. To keep
a single tag, tick it: the graph then shows exactly the pages carrying it.

## Switching the enhancement off restores the graph

Turning 「官方图谱增强」 off used to remove only the panel, toolbar and colouring; the nodes a
filter had already taken off the canvas stayed missing until the graph was closed and reopened.
Stopping the enhancement now hands the unfiltered data back to the renderer at once, so the
built-in graph is whole again the moment the switch goes off.

Nothing else changed.
