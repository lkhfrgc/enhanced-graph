The focused route on the built-in graph is easier to pick out.

## What changed

Focusing a note dims everything outside the route. The lit edges were already
drawn at full opacity, so there was nothing left to brighten — the surrounding
graph simply competed with them. The contrast now comes from pushing everything
else further back:

| | before | after |
| --- | --- | --- |
| Notes outside the focus set | 18% opacity | **6%** |
| Edges outside the route | drawn at 20% | **drawn at 5%** |
| Edges on the route | full | full |

The mechanism is unchanged; only the two multipliers moved. The unit test that
pinned the dimmed value now reads it from the module, so the next adjustment
cannot fail a test that was only ever checking a number.

No other behaviour changed.
