# Enhanced Graph — Obsidian 增强关系图谱

> 本文是中文完整版。目录页展示的是 [English README](README.md)。

给 Obsidian 加一个功能更强的关系图谱视图：**关联度引擎**、**Louvain 社区发现**、**图谱洞察**（惊奇连接 / 知识空白 / 桥接节点），基于 `sigma.js` 4.0 + `graphology` + `ForceAtlas2` 渲染。

> 提供两种用法：一个功能完整的**独立图谱视图**，以及在 Obsidian **原生图谱**上叠加的增强层（过滤、着色、洞察侧栏、聚焦）。两者共用同一套设置。

---

## 功能

### 1. 关联度引擎（Association Engine）

任意两个页面之间的关联度由四类信号加权求和：

| 信号 | 归一化 | 默认权重 | 说明 |
| --- | --- | --- | --- |
| **直接链接** | `(正向+反向)/2` | `×4.0` | 通过 `[[wikilinks]]` 直接相连；双向得满值，单向得一半 |
| **Adamic-Adar** | `saturate(Σ 1/ln(max(deg,2)))` | `×2.0` | 共同邻居按度数加权：越少见的邻居越有说服力 |
| **来源重叠** | `saturate(共享条数)` | `×2.0` | 共享同一 `frontmatter sources[]` 条目 |
| **共被引** | `saturate(共同引用者数)` | `×1.0` | 被同一篇笔记引用的两篇笔记 |

**每个信号都先归一化到 0–1 再加权**（`saturate(x) = x/(1+x)`）。因此权重就是**相对重要性**，浮层里的各项分数可以互相比较。

> 早先的版本把原始计数直接乘权重，于是「来源重叠 ×4.0」能贡献 12，压过互链的 6 —— 滑块上的数字并不表达它字面的意思，浮层也跟着误导。这个设计已废弃。

- 权重可在 `设置 → Enhanced Graph → 关联度权重` 中实时调整，改动即刻重建图谱。
- 悬停任意一条边即可看到四类信号的**完整分数拆解**。
- 命令 `复制当前页面的关联度报告` 会把某个页面的 Top-10 关联页面导出成 Markdown 表格到剪贴板。

### 2. 图谱可视化

- **着色模式一键切换**：按页面类型（实体 / 概念 / 资料 / 综述 / 对比 / 发现 / 论点 / 方法论…）或按 Louvain 发现的社区。
- **节点大小按链接数 √ 缩放**：`8 + √(degree/maxDegree) × 20`，大图自动整体缩小以免糊成一片。
- **边的粗细与颜色按关联权重变化**：**越弱越灰越细，越强越粗越亮**。宽度 `0.5 → 4.0`，颜色从灰渐变到亮端；**浅色主题方向相反**（越强越深），因为白底上「更亮」等于更看不见。两个端点都是中性灰阶（弱端带一点 slate 冷调以配合整体配色），不掺任何色相，所以颜色不会和节点配色抢注意力。
- **悬停交互**：悬停节点时邻居保持可见并高亮相连的边，非邻居变暗；同时弹出浮层显示该节点的**关联度分数榜**。悬停边时显示 `直接链接 / Adamic-Adar / 来源重叠 / 共被引` 四项拆解。
- **缩放控件**：右上角放大 / 缩小 / 适应屏幕，键盘支持 `+` `-` `0`。
- **位置缓存防抖动**：布局坐标持久化到插件数据里，数据更新时已定位的节点不会跳动，只有新节点参与布局。
- **图例自动切换，卡片可点**：类型模式显示各类型数量，社区模式显示核心节点标签、成员数与内聚度（低内聚社区带 ⚠ 标记）。两种模式的卡片都是开关——**单击排除/恢复**该类型或该集群，被排除的行留在原位并变灰，顶部「显示全部」一键恢复（没有可恢复项时置灰，永不移位）。两个视图的图例写的是同一份可见性设置，和过滤器面板里勾选框完全等价。
- 右键节点：打开笔记 / **聚焦邻居** / 隐藏此类型 / 复制关联度报告。
- **左键单击节点不做任何事** —— 聚焦交互统一走右键菜单，见下。
- 搜索框支持多词 AND 匹配，命中节点高亮。

#### 工具栏「外观」：细粒度设置

工具栏右侧的 **外观** 按钮打开一个面板，把「连线粗细 / 连线颜色 / 节点大小 / 节点颜色」四件事放在一起。

**连线的两端各自设定，中间自动过渡。** 不给「中间」任何配置项 —— 权重在 0 与 1 之间的连线，颜色和粗细都由两端线性插值得到：

| 控件 | 说明 |
|---|---|
| **低权重（弱关联）· 颜色** | 取色器（色环）+ 十六进制输入框；`↺` 回到主题 |
| **低权重 · 粗细** | 滑块 + **可直接输入数字**，范围 `0.2 – 12` |
| **高权重（强关联）· 颜色** | 同上 |
| **高权重 · 粗细** | 同上 |
| **恢复默认连线样式** | 一键把两端都还原 |

**节点颜色可以按类型或按社区逐个设置**：切到「按类型」列出全部 11 个页面类型，切到「按社区」列出图里实际的每个集群，每行一个取色器 + hex 输入框 + `↺` 恢复默认。选「单色」时则是一个全局取色器。

手感上的细节：

- **每个数值都能手输**：滑块旁边就是数字框，两者双向同步。粗细范围宽到 `0.2 – 12`，只靠拖拽落不到精确值。
- **每个颜色都有色环 + hex 框**：色环用来挑，hex 框用来输入或粘贴精确值（支持 `#abc` 简写，非法输入会退回原值而不是留下一个空色）。
- **两端的粗细互相独立**，所以也能配出「强关联反而更细」这种反向梯度。
- **拖动粗细即时生效**：由 sigma 的 reducer 每帧套用，不重建图谱。节点大小和颜色则要重建（尺寸写在节点属性里）。
- **外观与过滤分家**：过滤面板只负责「画什么」（类型、标签、是否隐藏孤立/结构页），外观面板只负责「长什么样」。两边不再各有一个「节点大小」。

实测（浏览器断言，非估算）：把强端宽度从默认改成 10，最强的那条边正好落在 10；最弱的边在权重 0.13，因此只按自己那一份从 `0.95` 走到 `1.73` —— 这正是插值该有的行为。再把弱端手输为 2.5，它才走到 `3.47`。

**布局区的「引力」调的是聚拢程度**（ForceAtlas2 的 `gravity`）：引力高时节点被拉向中心、社区收成一团，引力低时斥力占上风、整体铺开。实测归一化平均边长在引力 0.2→5 之间从 `0.170` 变到 `0.251`（**48%**），包围盒从 568 缩到 169 —— 形状和尺度都在变。

这里原先放的是「间距」，接 FA2 的 `scalingRatio`，**是个陷阱**：该参数对所有斥力等比缩放，等价于把整张图等比放大，而视图会自动 fit 到画布，于是完全抵消。同样实测：间距 0.5→2.5 时包围盒涨了 2.3 倍，但「平均边长 ÷ 包围盒对角线」只差 **0.6%** —— 看上去毫无变化。该旋钮已移除。

#### 工具栏「权重」：快速调整关联度系数

四个系数决定**哪些连线存在**，所以在看图谱的地方能改、改完立刻看到结果，比去设置页改完再回来重要得多。

面板列出 直接链接 / Adamic-Adar / 来源重叠 / 共被引 四项，各带数字框 + 步进按钮（0–8，步进 0.1），另有「恢复默认权重」，并直接标出默认值（4.0 / 2.0 / 2.0 / 1.0），让「恢复默认」是个可核对的目标而不是一句承诺。

**改权重必须重建图谱**——每一条边的分数都依赖这四个系数，无法靠重绘解决。面板上写了这句话，视图则把重建**去抖（700ms）**：拖动滑块时只在停下的地方重算一次，而不是每一格都重算。这是它与「外观」面板的本质区别——外观改的是画法，权重改的是数据。

#### 右键「聚焦邻居」：聚焦与两点连通

聚焦**只高亮，不放大**节点——放大是持续状态，会跟 √ 尺寸编码和「节点大小」设置打架，所以去掉了。被点过的节点额外画一个**标记环**：「邻居亮、其余变暗」并不能说明你点的是哪一个。

聚焦成对后，状态栏出现**连通范围**控件，可选「最短 / 经 N 点」：

| | |
|---|---|
| **最短** | 只画最短路径（默认，等价于原行为） |
| **经 N 点** | 额外纳入长度 ≤ N+1 跳的所有路径 |

两个设计点：

- **不枚举路径**。节点 v 落在预算 L 内的路径上，当且仅当 `d(A,v) + d(v,B) ≤ L`；边同理。所以两趟 BFS 就能描述**全部**这样的路径——路径条数随预算组合爆炸，但它们覆盖的**节点数**不爆炸。演示库 77 个节点、最高 41 度的枢纽，预算开到 4 跳也是瞬间返回。
- **低于最短距离的选项不显示**。若 A、B 本就相隔 2 跳，那「经 1 点」等于最短，显示出来只会让人以为点了没反应。屏幕上留下的每个按钮都**确实会改变结果**。

预算若被设得比最短距离还小（比如手改设置文件），会被抬到最短距离——**宁可钳制，也不让连通高亮凭空消失**。

聚焦的全部入口都在节点右键菜单里。菜单项的文字会跟着当前聚焦状态变化，所以它永远说的是「点了会发生什么」：

| 当前状态 | 菜单项 | 点击后 |
|---|---|---|
| 没有聚焦 | **聚焦邻居** | 高亮该节点**及其全部直接关联**（邻居保持可见，其余变暗），状态栏显示「已选：节点名」 |
| 已聚焦节点 A，右键另一个节点 B | **查看与「A」的连通路径** | 高亮**能连通 A 与 B 的所有链接** |
| 右键**已聚焦的那个节点** | **取消聚焦** | 清除高亮 |

- 两点连通用的是「**所有最短路径**」而不是随便挑一条 —— 两个节点之间往往有多条等长通路，只画一条会凭空造出一条主干。状态栏会显示「最短 N 跳 · M 条路径」；演示仓库里某对相距 2 跳的节点实测有 6 条路径，全部点亮。
- 两点不连通时：弹出提示「A 与 B 之间没有路径」，并**保留第一个聚焦节点**，方便直接换一个目标，不用重来。
- **取消聚焦的四种方式**：右键已聚焦节点选「取消聚焦」、单击**空白画布**、按 **Esc**、或点洞察面板上的**取消高亮**按钮。

判定只看**当前画出来的图**：如果某个类型或标签被过滤器隐藏了，经过它的路径不算连通 —— 否则会高亮一堆屏幕上看不见的节点。

#### 过滤器：按类型 + 按标签

- **按页面类型**：列出图里实际出现的类型与数量，逐个勾选排除。
- **按标签**：列出图里**全部**标签与数量（演示仓库 141 个），**按使用次数从多到少排序**，所以真正把图谱切分开的标签排在最前面。
  - 标签多到一个列表放不下，所以自带**搜索框**，输入即缩小范围（`retriev` → 1 行）。
  - 列表整份绘制，不截断；滚动由面板负责。
  - **勾选 = 这个筛选动作作用在这个标签上**，具体是排除还是保留由上面的模式决定：
    - **排除标签**（默认，也是初始模式）：勾选的标签，含它的页面被排除 —— 和旧版的存储含义完全一致，升级后原有设置照旧生效。
    - **包含标签**：只保留含勾选标签的页面。**首次进入时全部勾选**（什么都保留）。
  - **两种模式各自记住自己的勾选**：来回切换不会改写另一边的选择，回到某个模式时它的图和勾选都和离开时一模一样。
  - 「全选」勾上列表当前显示的全部行；「全清」清空当前模式的勾选 —— 在排除模式下等于「不再排除任何标签」，在包含模式下等于「什么都不保留」（空选择是一次明确的选择，不是没选过：没选过的状态是首次进入时的全选）。
  - **被勾选的标签会固定在列表顶部**，即使当前搜索词匹配不到它 —— 否则刚选中的那个标签会立刻消失，想改回来都找不到。
  - 搜索框右侧有「全选」和「全清」：作用于**列表当前显示的行**（搜索时就是匹配的那些）；没有可操作项时隐藏。
- 两条轴是**与**关系：一个页面只有在**不**被任何一条规则排除时才会画出来。
- 类型过滤仍是**减法**语义（勾选 = 排除）；标签过滤多了一个「只保留」模式，见上。

#### 工作区：读取哪个范围

- **只处理并显示工作区内的节点**：填了文件夹后，图谱**只读取**它下面的文件 —— 这是构建范围，不只是隐藏，所以集群、洞察、报告都只看这块。
- **直接输入路径**，不点选：
  - **「只读取」**：填 `notes` 或 `notes/deep`，留空 = 整个仓库。输入时**有路径建议**（列出仓库里所有文件夹及其笔记数），不必记住确切拼写。
  - **「排除文件夹」**：输入路径后回车，作为标签留在框里，点 ✕ 移除。排除**按前缀生效**：填 `templates` 会连同它下面的子文件夹一起排除。
  - 路径相对于仓库根目录，首尾斜杠可省略。
- **每个输入框下面写清这条路径意味着什么**：「该文件夹及其子文件夹共 27 篇」／「匹配 2 个子文件夹，共 15 篇」／**「仓库里没有这个文件夹，图谱会是空的」**（后者标黄）—— 打错一个字母原本只会得到一张空图，原因不可见。
- **设有「应用」按钮**：输入只是暂存，按下按钮才写入设置并重建图谱 —— 别的开关都是重绘级别、点一下立刻生效，这个要重新读一遍仓库，误触会让图谱空一阵子。有改动时按钮才可用，旁边出现「撤销改动」。
- 存储上是一个工作区根 + 若干排除前缀（`workingFolder` / `excludeFolders`），两个视图的面板说的是同一份状态。
  - **限制**（如实说明）：这套模型表达不了「两个互不相邻的根」，例如「只要 `work/` 和 `personal/`，但不要 `work/archive/`」。这种需求目前只能用「整个仓库 + 排除其余」近似，而排除是按前缀的，新出现的文件夹不会被自动排除。

### 3. Louvain 社区发现

- 基于 `graphology-communities-louvain` 自动发现知识聚类，**独立于预定义的页面类型**。
- **内聚度评分**：`实际内部边数 / 可能边数 = intraEdges / (n·(n−1)/2)`；`内聚度 < 0.15 且 ≥ 3 页`的社区标记为稀疏并在图例中告警。
- **12 色调色板**：社区按规模从大到小重编号，保证配色稳定；超过 12 个社区时循环取色。
- **跨重建稳定**：Louvain 的随机数发生器使用固定种子，并将上一次的社区 id 按成员重叠映射回来，因此编辑笔记后集群**不会重新配色**。

### 4. 图谱洞察

**惊奇连接（Surprising Connections）** —— 复合评分排序最值得注意的边：

| 信号 | 加分 |
| --- | --- |
| 跨越社区边界 | +3 |
| 连接相距较远的类型（资料↔概念、资料↔综述、查询↔实体…） | +2 |
| 连接不同类型 | +1 |
| 边缘页面连向核心枢纽（`min(deg) ≤ 2` 且 `max(deg) ≥ 最大度/2`） | +2 |
| 弱连接但确实存在 | +1 |
| 共享 ≥ 2 个原始资料 | +2 |

**知识空白（Knowledge Gaps）**：

- **孤立页面**（度 ≤ 1）—— 与 Wiki 其余部分缺少连接的页面。
- **稀疏社区**（内聚度 < 0.15，≥ 3 页）—— 内部交叉引用薄弱的知识领域。
- **桥接节点**（连接 3+ 个集群）—— 维系多个知识领域的关键枢纽页面。

**交互**：点击洞察卡片高亮图谱中对应的节点与边，再次点击取消；点 `×` 标记为已查看（持久化保存，可在设置里一键恢复）。

### 5. 官方图谱增强（默认开启）

开启后，本插件会在 Obsidian 内置的关系图谱上叠加：

- **社区着色** —— 按 Louvain 集群给节点重新上色
- **关联度浮层** —— 悬停节点时显示它的 Top-5 关联页面及分数，并链式调用官方原有的悬停行为
- **洞察侧栏** —— 在官方图谱里注入社区图例 + 惊奇连接 / 知识空白卡片，复用同一套 `insights-panel` 渲染
- **点击聚焦** —— 点卡片即聚焦到对应节点及其邻居

设置项是一个开关（**默认开启**）；开启后配色由内置图谱自己的工具栏在「按社区着色 / 按页面类型着色」之间切换，设置里只记住那个选择。命令面板还有 **切换官方图谱增强** 与 **检查官方图谱接口兼容性**。

> 这一层与 Obsidian 的版本绑定。运行环境不支持时，增强会**静默停用**：官方图谱保持完全可用，只是不再有这些附加功能。插件不会修改 Obsidian 的任何文件，卸载后不留痕迹。

**做不到的事**：官方图谱只画真实存在的 `[[wikilink]]`。关联度引擎里最有价值的**非链接关联**（来源重叠、共享资料、共同邻居）在官方图谱中没有对应的边，因此无法在官方图谱上画出来——这些仍然要看插件自己的独立视图。

### 6. 复用内置图谱的布局

内置图谱会在内部算好每个节点的坐标。开启「复用内置图谱的布局」（默认开启）后，独立视图会**直接采用这套坐标**，于是：

- **省掉主线程的 ForceAtlas2** —— 大仓库不再有分块计算的卡顿
- **两个视图的节点位置完全一致**

采样发生在图谱重建时，是**一次性快照**而非实时镜像（内置图谱是活的，实时跟随既费又晃眼）。想重新对齐可以用命令 **从内置图谱同步布局**。

快照的健壮性：

- **覆盖率门槛**：映射到的节点少于 60% 就判定快照不可用，回退 ForceAtlas2。局部图谱、或者内置图谱上挂了搜索过滤时，覆盖率天然不足，会自动回退。
- **缺口插值**：快照没覆盖到的节点，按 Obsidian 自己的做法落在**已定位邻居的质心**加一点确定性抖动；完全没有已定位邻居的走黄金角螺旋。全程无随机数，同一份快照永远得到同一张图。
- **状态栏会写明来源**：`布局：内置图谱（graph）` 或 `布局：ForceAtlas2`。

引擎层（`core/`）与视图层（`view/`）都不 import Obsidian 的具体实现细节：

- `core/` 通过 `VaultAdapter` 访问文件，因此可以在 Node 测试与浏览器里直接跑。
- `view/` 只用 DOM + sigma，`obsidian` 仅用于 `ItemView` / `Notice` / `setIcon` 等外壳。
- `integrate/` 是唯一与内置图谱对接的层，全部做了探测与降级。

### 分层与依赖方向

依赖只能自上而下，越靠下的层越可复用、越不知道上层的事：

```
app         main.ts、settings.ts（组装根：只做接线）
  ↑
integrate   official-*.ts（与内置图谱对接；可以用 view 的积木）
  ↑
view        renderer / graph-view / layout / palette …（通用渲染，不与内置图谱打交道）
  ↑
core        parse / relevance / communities / graph-builder / insights（纯引擎，不 import obsidian 与 sigma）
  ↑
contract    types、i18n、settings-model、plugin-host（纯词汇表，不 import 任何东西）
```

四条可执行的约束，由 [`test/architecture.test.ts`](test/architecture.test.ts) 断言：

1. **`core/**` 不得 import `obsidian` 或 `sigma`** —— 引擎因此能在 Node 里单测，也不会被 Obsidian API 或渲染库的变更波及。
2. **`view/**` 不得 import `integrate/**`** —— 独立视图不依赖内置图谱适配层；箭头只朝一个方向，适配层可以整个删掉而不动视图。
3. **不允许运行时循环依赖**（`import type` 会被 esbuild 抹掉，单独统计）。
4. **每个第三方库只出现在一个模块里**：`sigma` → `view/renderer`，`graphology-layout-forceatlas2` → `view/layout`，`graphology-communities-louvain` → `core/communities`，`js-yaml` → `core/parse`。想换掉其中任何一个，都只改一个文件。

### sigma 4.0 迁移说明

用的是 `sigma@4.0.0-beta.8`（npm 的 `latest` 仍是 3.0.3，v4 只发在 `beta` 标签下）。迁移由上面第 4 条兜住：**只动了 `renderer.ts` 一个模块**。

v4 与 v3 的差异（都已在代码注释里写明原因）：

| v3 | v4 |
|---|---|
| 设置写在构造参数顶层 | 收进 `settings: {}` |
| reducer `(key, data)` 返回**整体替换** | `(key, displayData, attrs, …)` 返回 **partial 合并** |
| `labelColor` / `labelSize` / `labelWeight` 是全局设置 | per-node 的 `labelColor` / `labelSize` / `labelFont` |
| `defaultDrawNodeHover` 手绘悬停气泡 | 声明式 `backdrop*` 字段 |
| `data.hidden` / `data.forceLabel` | `visibility` / `labelVisibility` |
| `camera.animatedZoom/Unzoom/Reset` | `zoomIn` / `zoomOut` / `reset` |
| 标签画在 2D 画布上 | WebGL SDF 图集，**没有 2D 标签层** |

**踩到的两个 v4 坑**（都已绕过并注释）：

1. **`Sigma.setGraph()` 不会重建内部管理器（如 DragManager）。** 它们是在构造函数里用直接引用建出来 — 换图后仍指向旧图。因此本插件刻意**复用同一个图实例**（`clear` + 重填），而不是 `setGraph` 一张新图，以此保住相机与 reducer。
2. **`itemSizesReference` 默认值从 `"screen"` 变成 `"positions"`**，节点随缩放按 `sqrt(1/ratio)` 缩小。旧的 `maxCameraRatio: 12` 因此够不到标签剔除阈值（实测最小节点 10.8px vs 阈值 4px），等于悄悄废掉「缩小时自动隐藏标签」。上限改为 120。

5. **没有任何模块 import `main.ts`** —— 组装根不参与被依赖。

另外：**Obsidian 的图谱视图类型字符串只出现在 `src/integrate/official-internals.ts`**。Obsidian 更新导致增强失效时，只需要看这一个文件，先跑命令「检查官方图谱兼容性」看哪些环节断了。

`npm run architecture` 会打印实测的模块规模、扇入扇出、依赖环与分层违规。

`harness/` 是一套浏览器测试台，用桩替换 `obsidian` 模块后挂载**真实视图代码**，用于验证 WebGL 渲染、悬停语义、图例与洞察面板。

## 设计说明与已知取舍

- **稀疏社区为什么罕见**：Louvain 以模块度为目标，天然倾向把连接紧密的节点归为一组，因此内聚度 < 0.15 的社区只在**规模较大且内部稀疏**时出现（例如 15 个节点、15 条内部链接 → 内聚度 0.143）。这是指标本身的性质，不是判定逻辑的问题；示例仓库 `安全与对齐/` 就是按这个拓扑构造的演示集群。
- **Adamic-Adar 的度数口径**：使用**去重后的无向邻居数**，而不是 `出链 + 入链`（后者会把互链算两次）。这是更标准的定义。
- **`sources[]` 归一化**：去掉路径、扩展名、`[[ ]]`、`|别名`、`#锚点` 后小写化；`Attention-Is-All-You-Need` 与 `Attention Is All You Need` **不会**视为同一个来源（只折叠空白，不折叠连字符）。
- **默认隐藏 `type: query`**：研究/查询类产物不计入知识图谱；可在过滤器里打开。
- **官方图谱增强会覆盖 color groups**：开启时按社区/类型接管着色，关闭或卸载时把**原始颜色逐个还原**（原本没有颜色的节点会删掉该字段，而不是留一个 null）。
- **拖动画布时不会隐藏连线和文字**：sigma 的 `hideEdgesOnMove` / `hideLabelsOnMove` 默认面向大图谱，在正常仓库上会让图谱在拖动时"空掉"——`hideLabelsOnMove` 会在 `render()` 里提前返回，把标签、边标签**和高亮**一起跳过。现在按规模自适应（>600 节点才隐藏边，>1500 才连标签一起隐藏），阈值在 [`src/view/tuning.ts`](src/view/tuning.ts)。
- **Deep Research 暂未实现**：曾实现过基于 OpenAI 兼容 API 的研究主题生成，按需求已整体移除（无 LLM 客户端、无网络请求）。知识空白卡片保留点击高亮等全部本地能力。
