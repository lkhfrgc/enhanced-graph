## Works better together with scholar-llm-wiki

[scholar-llm-wiki](https://github.com/lkhfrgc/scholar-llm-wiki) builds the kind of vault this
plugin is for — AI agents compile papers, books and notes into a structured, densely
interlinked wiki. A dense link graph is what makes the association engine and the insights
panel worth having: the scoring has something to score, and the structural cards have
something to find.

The line sits directly under the title in both READMEs, each in its own language:
**Works better together with scholar-llm-wiki** in `README.md` — the one the directory renders
— and **结合 scholar-llm-wiki 使用更佳** in `README.zh.md`.

No plugin code changed in this release.

1.3.2 added this line to both files in Chinese, which put the wrong language on the directory's
entry page. This release is that correction, and nothing else.
