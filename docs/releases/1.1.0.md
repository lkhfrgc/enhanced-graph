A release about control: what the graph draws, what the panels show, and how the
two views agree with each other.

## The built-in graph enhancement is on by default

The setting used to be three states — off, colour by community, colour by page
type — so one control both turned the enhancement on and chose how it coloured.
It is now a plain switch, **on by default**, and the colouring is picked where it
can be seen: the built-in graph's own toolbar.

Upgrading does not change anyone's graph. A settings file that only knows the old
key keeps the state it was actually in — off stays off, and a colouring in use
stays on with that colouring.

## Tag filtering has two modes

Each tag row is a tick, and the mode above the list says what a tick means:

| Mode | A ticked tag means |
| --- | --- |
| **Exclude** (default) | pages carrying it are hidden |
| **Include** | only pages carrying it are kept |

The two modes **keep their own ticks**, so switching back and forth never rewrites
the other one. `Select all` ticks every row on screen; `Clear` empties the
selection — which, in include mode, means keep nothing: an empty selection is a
choice, not the absence of one.

## The legend's cards are controls again

In both views, clicking a type or cluster card excludes it and clicking it again
brings it back, and the header carries an always-present "show all" that is greyed
out while there is nothing to restore. The two views write the same visibility
settings the filters panel does, so a card and a checkbox can never disagree.
The list also keeps its scroll position when a click re-renders it.

## Panel and search fixes

- **One length for the panel.** It used to shrink to its content, so switching
  from the insight cards to the filters resized the box under the pointer. Every
  tab is now as long as the space above the legend, and longer content scrolls
  inside it. A short tab still stays short.
- **Every tag is listed.** The tag list was cut off at 40 rows and the inner list
  stopped at a fixed height; both limits are gone, so a tag you can see is a tag
  you can switch off.
- **Search marks follow the canvas.** The marks are drawn on our own layer in
  screen space, and only the focus kept that layer redrawn. A search's marks
  stayed where they were put while the graph moved under them; the ticker now
  covers both.
- **The built-in graph's edges follow the theme again.** The plugin kept a copy of
  the graph's shared edge colour from when it attached and wrote it back on every
  refresh, so a theme switch left the previous theme's ink on screen until the
  graph was reopened. With no custom colour chosen those objects are no longer
  written to at all.

## Labels

- **Colour comes from the theme**: black on the light theme, white on the dark
  one. The colour picker is gone.
- **Opacity replaces it**, 0–100%, because that is what is left to tune once the
  colour is not a choice: labels are drawn inside the node, on top of the graph.
- **"Hide labels when zooming out" now really means it.** Sigma culls labels twice
  — a size threshold, and a grid that keeps `density / zoom²` labels per cell.
  Only the threshold was wired to the switch, so labels went on disappearing as the
  graph was zoomed out. Both are wired now.

## Smaller things

- Removing a focus no longer clears the search marks that share the same layer.
- The weights panel and the rebuild button are gone from the built-in graph: the
  coefficients live in the settings tab and the standalone view, and the built-in
  graph keeps itself in step with the vault.
- A cluster's card, a type's card and the filters panel all read and write the
  same settings, so the same click means the same thing wherever it is made.
