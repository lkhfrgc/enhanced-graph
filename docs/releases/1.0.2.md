First version to pass the directory's automated review.

## What the review caught

The 1.0.1 submission failed on three errors and a number of warnings. All of them
are fixed here; none of the fixes changes how the plugin behaves.

**Errors**

- The plugin detached its view leaves in `onunload`, which resets a view to its
  default location — a user who had moved the graph to another pane would find it
  back where it started. The leaves are no longer detached; Obsidian tears them
  down itself.
- Settings headings were plain `<h2>` elements. They now go through
  `new Setting(containerEl).setHeading()`, so they match every other setting row.
- Five places assigned literal styles (`style.cursor`, `style.display`) instead of
  using CSS classes.

**Warnings**

- The README is now in English, with the full Chinese version at
  [`README.zh.md`](https://github.com/lkhfrgc/enhanced-graph/blob/HEAD/README.zh.md).
- `LICENSE` is the unmodified GPL-3.0 text. A project-specific copyright line had
  been prepended, which stopped GitHub recognising the licence — the copyright is
  recorded in `NOTICE` instead.
- `npm run build` now writes `main.js` into the repository root rather than into a
  vault outside it, which is why the build verification reported that no
  `main.js` was produced. `npm run build:vault` keeps the old behaviour for local
  development.
- The graph builder reads the configuration folder name from the vault instead of
  assuming `.obsidian`.
- `requestAnimationFrame` and `setTimeout` are called on `window`, so a graph in a
  popout window animates.
- The interface language comes from Obsidian's `getLanguage()` rather than reading
  `localStorage` directly.
- Two informational `console.info` calls were removed; the status bar already
  reports what they logged.
- Unused imports and an unused counter were removed, and an unnecessary escape in
  the wikilink pattern was dropped.

## Known limitations

- **The built-in graph only draws `[[wikilinks]]` that exist.** Non-link
  associations — source overlap, common neighbours, co-citation — have no edge
  there, so they are only visible in the standalone view.
- **"Related notes" can return fewer than five.** Pairs scoring zero are dropped
  rather than given a floor score.
